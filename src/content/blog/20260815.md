# 友人とBBQ
　ずっと構想があったんですよね、BBQ。いろいろと話し合いを重ねた結果、刈谷市の洲原公園という場所のBBQ場を使ってみんなでバーベキューをすることになりました。  
　当日は主催とその運転手がメインに買い出しを行い、私もクーラーボックスの持参や氷の購入などをして協力をしたのですが、なんと買い出し班が肉を4kgも買ってきました。バカか！！！！！！！まあ事前に買い出しリストをみんなで作ったんですけど、気づいたら98項目くらいになってたんですよね。こうなることは簡単に想像がついた。

# 大相撲本場所初観戦！
　本当に念願ですよ、一応地元巡業で観戦経験があるので本場所初観戦という表記にしています。まあ巡業はあくまで花相撲ですから、ガチの勝負が見られる本場所、楽しみでしかなかった。  
　前述の地元巡業は市民先行販売によって5列目のチケットが簡単に手に入ったのですが、本場所のチケット争奪戦は過酷。まず[相撲茶屋]{公式転売ヤー}の存在だったりファンクラブ有料会員先行だったりと、日常的に追ってない人がチケット取るのって無理ゲーに近いんですよね。こんなに観戦人気と競技側の人気が釣り合っていないスポーツあるのかな。とにかくいい席で見るにはコネが必要、ということで名古屋場所ならではの手段でチケットを抑えてもらいました！！(スゲーーー)
<div class="mx-auto flex flex-col items-center justify-center ">
<img src="/posts/20260815/4.jpg"/>
座席からの眺めはこんな感じ
</div>

　イスSS席の2列目を抑えてもらいました。ソロ観戦だから仕方ない。カメラの性能が良くないのと掲載用に画質を下げているのでよくわかりませんが、肉眼では十分近い距離でした。取組中は息遣いも聞こえてくるんですよ。なんと。  
　観戦したのは4日目です。ここまで上位陣はすごく安泰だったのですが、この日は豊昇龍関以外ほとんど総崩れだったような。何を見せられているんだ。結びの大の里関の取り組みもまさかの庄之助差し違いで大の里黒星。あれは同体でも良かったんじゃね？とは思ったけどな  
　というかIGアリーナやっぱり綺麗ですね。そして空調がめっちゃ効いている。近くのおばさんたちがドルフィンズアリーナと比較して凄く涼しいことに感嘆していました。
<div class="mx-auto flex flex-col items-center justify-center ">
<img src="/posts/20260815/5.jpg"/>
こんなにうまいものを毎日…
</div>

　サブアリーナでは物販や出店がありました。この物販がね、本当に種類豊富すぎて驚いた。グッズと言われて思い浮かぶもの全部網羅してるんじゃないの？ここでは祖母用に若隆景関タオルと和菓子、自分用に一山本関、大の里関タオル、四股名扇子、力士Tシャツを購入しました。ちょっと買いすぎた。  
　写真は出店で頼んだソップ炊きです。めちゃくちゃ美味い！！力士って毎日こんなうまい飯いくらでも食っていいのかよ！！(歪んだ見方)
