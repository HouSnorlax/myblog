# はじめに
　この度の自らの過ちに関して、もうこれ以上反芻するのはやめようと考えてはいるものの、いつまで経っても止まらないためにここに思っていること全てを吐き出すことで止めるための一助とする。文章の中には牽強附会な理屈も混ざっているかもしれないが、心中は本当に申し訳ない気持ちでいっぱいである、ということだけ補足して、本題に入る。

# 前提
　まず今回の問題を引き起こしてしまった原因として、次に挙げる私の性質が大きく関わっているだろう。  
1. 如何なる時でも人恋しい
2. 自分の尺度で考えてしまう
3. 精神不安定

## 如何なる時でも人恋しい
　会話をしていないと気が済まない。深夜、作業中。人など居る筈ないが、何処かで通話が開かれていないか探してしまう。元の性格がこれであるから、交際相手となれば毎秒レベルで会話がしたい、そんな感情を抱いてしまうのである。  
　また、この考え方は体調が悪い時でも変わることはない。どれだけ喉が痛くても、頭が痛くても、辛い状況を緩和するためにチャットをする。会話をする。寂しさを埋めるためならば痛めている個所を更に痛めることくらいは厭わない。  
　では寝込むほどの体調ではどうなるだろうか。これは自分でも分からない。実は最後に病気で寝込んだのは2018年、インフルエンザに罹患した時が最後である。当時はSNS等の人間関係もさほど持っておらず、もはやその時のことなど覚えていない。コロナウイルスにも罹ったことがないので、病気のしんどさが分からない。

## 自分の尺度で考えてしまう
　突然だが私は複数人で旅行に行くのが大好きだ。また交通機関に関する知識を多く持ち合わせているために旅程を組む担当もよく請ける。ここで問題になるのは、毎度私の体力に合わせたハードスケジュールを組んでしまうこと。私は夜行バスで早朝に現地入りし、出来るだけ多くの個所を回った後、深夜に夜行バスで帰るという旅をよくする。こんな旅行ができる体力を基準にして旅程を組んでしまう。直さなければいけない面であることは分かっているのだが、直し方が分からない。とにかく、私がこうであるのなら、全人類こうであろう、と勝手に考えてしまう。
## 精神不安定
　最たる要因である。基本的に何に対しても常に怯えている。気の知れた仲間内で開かれるボードゲームにすら参加できない程に怯えている。少しでも上手くいかなさそうな要素がある物事に対して、信じられない程思い詰める。人間の心境変化が怖い。家族、友人、先生etc... あらゆる感情の変化や接し方の変化、その全てが自分の所為で変わっているような気がして、恐怖する。  
　またここ最近は卒業研究の進行方針が迷子になってしまい、心の安寧が全くと言っていいくらいに無くなっていた。こうなると待っているのは奇行である。酒をドカ飲みしては狂っている様子、名大祭で夜の踊り子ダンスを踊っている様子…あらゆる奇行をインスタグラムのストーリーに載せた。あれだけ優しかった先輩が突然狂いだして奇行を繰り返す(本性が暴かれた、とも言える)。失望を通り越して怒りに変わることは想像に容易い。  
　行動に一貫性が無くなるという点も大きな特徴だろう。実際、すれ違いが起きてしまった前後も、インスタグラムはしばらく見ないと宣言しておきながらその日の深夜にストーリーを見始める、雀荘に20時まで居ようとしていたはずが突然閉店時間まで残りカラオケで一泊し始める……など。もはや冷静さを欠いているという表現を超越するような、衝動だけで躰を動かしていた。
# 結局何を求めたことですれ違いが起きたのか
　何時でも気軽に話すことが出来て、沢山遊びに行くことが出来る、そんな関係を欲してしまった。一人の時間が大切であるという性格を知っておきながら。付き合う前はストーリーのほぼ全てにいいねを付けてくれたり、会える機会をモチベ、嬉しいと言ってくれたり。付き合った後暫くしてそれが無くなったのは興味が薄れたからなのではないかと不安になってしまった。(もともと気を引くために無理していて、安堵から行動を抑えたのだと信じたい)  
　一度不安を覚えてしまうと止まらなくなる。しばらく距離を置くのが正解であると分かりながら、どうすれば以前のような反応を引き出せるか試行錯誤してしまう。厳密に言えば連絡を控えていた時期はあったが、それを完遂できていたかと言われるとNOだろう。そして、とうとう本人の中での大事な変化に対して、茶化すような口調でメッセージを送ってしまった。この発言はノートで嫌悪感を示す投稿があったことで撤回した。漸く自らの暴走に気づき、暫く連絡を止めようと思った。本当にこの時は当面の間一切の接触を止めて一人にしてあげようと思っていたのです。
# 精神崩壊
　前述の通り、インスタグラムはしばらく見ないと宣言しておきながらその日の深夜にストーリーを見てしまった。これが良くなかった。「偏差値差のある人間との会話は疲れる」という内容のストーリーによって私を繫ぎ止めていた何かが、何かが、何かが……崩壊した。崩壊した。  
　抑々、この内容を自分宛であると思い込むこと自体、「お前は俺よりも下だ」と認めているようなことであって、そんなことをされて怒らない人はいない筈だ。そんな当たり前のことが考えられないくらい余裕がなかった。凄く言い訳がましいが。糖質がましい私の性格が、「つまらない」、その言葉が、全て自分に向けられたものだと思ってしまった。私は面白いことが大好きだ。自分がちょけるのも大好きだし、他人がバカやってる様子を見るのも大好きだ。面白ければ何でもいい。その生き方を全て否定されたものだと思って自暴自棄になった。只管泣いた。今考えれば冷静に時間を取って、客観視などしてから今後の自分の在り方を決めれば良かったのだが、出来なかった。間違いなく人生で一番心が沈んでいた日にそれが出来る筈がなかった。結果として、ヒステリーを起こしたとしか思えない文章を、人生で最も愛していた筈の人に、衝動が送信していた。
# 結局どうすればよかったのだろうか
　一か月半経ってようやく落ち着き始めた心が出した結論は、「最近調子に乗りすぎてしまい申し訳なかった。沢山お出かけしたいし、色々お話ししたいと勝手に思ってしまった。もう少し君の心を汲み取れるよう頑張る。」の声掛け。これが正解であるとは確信しないが、ヒステリーを起こすよりは確実にマシであることは間違いないだろう。ただ、この結論に辿り着くまで一か月半も掛かっている時点で、私は彼氏となる人間としては不適格だったと思う。実際、ヒステリーを起こした後の謝罪文は兎に角酷いものであった。自分でも思い出したくない。弥縫策。ダサい。気持ち悪い。しかもこの男、芥みたいな謝罪文を送った後に「頭冷やしてきた」と言って追い謝罪を送り、それに既読が付かないことによって更にメンタルを壊してLINEのプロフィールを毎日変える狂行に走り出した。  
<span class="text-3xl">全部僕が悪いです！僕の性格が幼稚であったから！人の心を考えられないから！本当に、申し訳ありませんでした……</span>  
　何様なんだと思われるかもしれないが、私からも幾つか物申させてほしい。「一言欲しかった」LINEを一週間放置するときも、気に障る発言をしてしまった時も、後からならば私も心中を察することは出来る。でも何か一言あるだけで、安心感が違った、齟齬は生まれなかった、そう思う。  
　ヒステリーを起こした、しかもそれが男の行動…そんな奴に取る時間など無いのは普遍的な原理だと思うが、話し合いくらいはしたかった。仮にも爾汝の交わりとなった関係であるのだから、X(旧Twitter)での関係のように無言でブロックして終わりなんてどうなの…と思ってしまった。このようなことを言うのは烏滸がましいと理解はしている。

# おわりに
　多分自分の力だけでは落ち着くことが出来ないので、来週は京都の安井金比羅宮に行って後のことは神様に任せたいと思います。最強の縁切り神社として名高い神様ですが、別に相手の不幸を願うことはしません。自分自身を見つめなおすきっかけ作りにしようと考えています。そして、縁切りだけでなく縁結びにも効果がある神社です。なので一つ願い事をして終わりにしようと思います。「貴女が理想の相手と出会える日が訪れますように」
