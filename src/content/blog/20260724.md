# 近況
　結局花火大会のデートは幻になってしまいました……ただ元々行くつもりであった花火大会の予定をデートにすり替えたので、元通りになったとも言えます。祖母と一緒に祭りを回ることにしました。関東に行ってしまったらさすがに祭りのためだけに帰省をするのは難しいですし、祖母もそろそろ後期高齢者…何時まで会えるか分かりませんですから、生まれた時からお世話になった人に恩返しをしていきたい。  
　そして慰みとして妹とナガシマジャンボ海水プールに行くことになりました。
<span class="text-3xl">え、水着デートやん。アツ。</span>  
　というかやっぱりこうやって二つ返事で承諾してくれる人が自分にはめちゃくちゃ合うわ

　家内のことはこれくらいにして、6,7月は[自暴自棄]{やぶれかぶれ}になっていた勢いでいろんなイベントに参加していたので、近況報告、始めま～～す！！！(あ、[新機能]{ルビを}導入しました)

　ということで6th公演全通を達成したのに続いて、7th東京公演にも行ってきました～～～！！  
　実は正直この日までは完全にモチベ無くなってたんですよね、勢いでSS席取ったけど高すぎるだろ、次からは行ってもSでいいかみたいな…アプリの方も時間がなくて全く触れず…(実はこの記事を書いているときも全く触れてません、まだラーメンシナリオやってない)  
　そんでもってめちゃくちゃ病んでたので公演中もあまり集中できてませんでした。声はめちゃくちゃ出るんだけどね。  
　勿論ですがめちゃくちゃ楽しかったですよ！！結果として。やっぱりなあ、僕には現場しかないんですよ……とりあえず高まった曲でも挙げていくか  
1. Special Record! → Glory Eyes  
7th東京D1を一言で説明するならこれじゃないの。曲のMIX自体は5thで経験済みだけどまさか今になってやってくると思わなかったからビックリした。会場のコールも仕上がっていて凄くよかったと思う。  
2. O-ロライズ  
　シャーたんがいるから予想してた人はいくらかいたけど、正直僕はやると思ってなかったから驚いた。やっぱり津田美波パイセンがアツすぎる。本音を言えばサビは飛びたい。  
　他にも満を持しての『ふたり』披露であったり、デジたんソロの狂気だったりと挙げたい個所は沢山あるけどこの辺で。
# ウマ娘7th EVENT THE STAGE TOKYO DAY2

俺がVIPだ！！！！！！

　なんと二日目はご縁があってVIPの連番に入れてもらいました。信じられない。ステージがガチで近い、トイレに困らない、水ある、椅子豪華、150/12000の狭き門ではあるけどこれはいい参戦体験ができるわ～ええな～と思いました。今までずっと連番してきた友人には抜け駆けで連番者を見つけてしまった形でしたが、なんと友人はD1の前日に連番者が見つかったらしい。それはそれですごいな  
　さて、セトリの方ですが印象的なことが多すぎて何をどう語ったらいいかわからん。まず一曲目変えてくるとは思いませんでした。これから全公演一曲目はUMA IN 〇〇で行くのかなと思ったのですが海外公演はどうなるんだろう。  
　一曲目が終わるとMCの時間ですね。せっかくのVIP席なので演者の皆さんをまじまじと見ることにします。……ん？  
<span class="text-3xl">和泉風花さん、可愛すぎじゃないですか？</span>  
　一発で落とされました。なにこれ。俺がお兄ちゃんです。もう力の抜けた表情でペンラを適当に握りながら見つめることしかできませんでした。ペンラを推しの色にしましょう！のタイミングでちょっとコンタクト取れた気がして嬉しかった。首傾げた姿マジで可愛かったよ。  
　他にも語ることが多すぎるので披露順に絞って感想書きたいと思います。  
1. トレセン音頭  
俺をライブ沼に沈めたのは間違いなくこの曲だから久しぶりに聴けて本当に嬉しかった。コールは半分忘れていました。  
2. めにしゅき  
ブエナ(CVいずみふ)に沼りかけてた自分を完全に落とした原因　「きゅっきゅん♡」の破壊力ヤバすぎてアーカイブはそこばかり観てたよ
3. UMA Summer  
俺このために毎公演絶対にクルクルのタオル持ってきてるからさ、毎公演やってくれよ　お気持ち野郎とか知ったことか  
4. トレセンラーメン列伝  
和泉風花さんが可愛かった　星5  
5. Gold-Triumph  
これ堕ちない訳がなくない？なにこれ、中王区ですか？  
6. Everlasting BEATS  
いつか発表後即披露、やるとは思っていたんだけどいざやられると平常心ではいられなくなるな　あまりにも連続してやられるとハイハイいつものね、になりそうだから忘れかけたころにまたやってほしい
7. UNLIMITED IMPACT  
カメラマンのプロンプト見えちゃって何やるか先バレした。VIP席ってそういうこともあるのか。正直フォーエバーヤング役は既に大物となった声優に任せるのかなと思ってたんだけど、ラスサビの歌唱を聴いてこれは納得のキャスティングだな、と思えた  
　正直もっと書きたいことあるけど記事が長くなりすぎるから終わり！
